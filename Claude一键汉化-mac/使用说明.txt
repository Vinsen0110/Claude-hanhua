Claude 桌面版一键汉化（macOS）
================================

把 Claude 桌面版的界面换成中文。适用于装在“应用程序”文件夹里的 Claude 桌面版。


一、怎么用
----------
1. 先保存 Claude 里正在进行的工作（安装时会自动退出 Claude）。
2. 双击“Claude一键汉化.command”，会打开一个“终端”窗口。
3. 按回车开始，按提示输入这台 Mac 的开机密码（输入时屏幕上不显示，输完按回车）。
4. 等 2～3 分钟，Claude 会自动以中文重新打开。
   如果还是英文：点左下角账号菜单 → Language → 简体中文。


二、双击打不开怎么办
--------------------
从网上、微信或隔空投送收到的文件，第一次打开时 macOS 可能提示“无法验证开发者”。
  · macOS 14 及更早：右键点脚本 → 打开 → 再点“打开”。
  · macOS 15 及以后：先双击一次，然后打开 系统设置 → 隐私与安全性，
    拉到底部点“仍要打开”。
也可以不双击，直接打开“终端”，输入 bash 加一个空格，把脚本拖进终端窗口，按回车。


三、常见情况
------------
· Claude 自动更新后又变回英文：再双击运行一次本脚本即可。
· 想恢复英文原版：再双击运行一次，选“2 恢复英文原版”。
· 提示“终端”无法修改 App（Operation not permitted）：
  打开 系统设置 → 隐私与安全性 → App 管理，允许“终端”，再运行一次。
· 提示没装“命令行开发者工具”：按弹窗安装，或在终端运行 xcode-select --install，装好后重试。
· 下载补丁失败：脚本要从 github.com 下载补丁，国内网络可能需要开代理。
  也可以先用浏览器下载补丁的 .tar.gz 源码包，再在终端运行：
  bash Claude一键汉化.command --from 下载好的文件路径


四、它做了什么
--------------
· 从 GitHub 下载开源项目 javaht/claude-desktop-zh-cn（MIT 协议）的最新版补丁，
  由这个补丁完成实际汉化；本脚本只负责下载、检查环境和调用它。
· 修改前把原版完整备份为 /Applications/Claude.backup-before-zh-CN-日期.app，
  恢复英文时就用这份备份。
· 修改后 Claude 的官方签名会换成本机签名，这是补丁的正常结果。
· 用官方账号登录后，部分由网页提供的内容（如账号设置页）可能仍是英文，补丁管不到这部分。
· 不会上传任何数据，也不会安装常驻程序；临时文件在运行结束后自动删除。


五、高级用法（在终端里运行）
----------------------------
  bash Claude一键汉化.command --lang zh-TW     繁体中文（台湾），zh-HK 为繁体中文（香港）
  bash Claude一键汉化.command --restore       直接恢复英文原版
  bash Claude一键汉化.command --dry-run       只在临时副本上试运行，不改动已安装的 Claude
  bash Claude一键汉化.command --version 1.4.19   指定补丁版本
